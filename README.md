# VanhKhuc Contact + CV

Static portfolio website for GitHub Pages.

## Files
- `index.html`: Contact page
- `cv.html`: CV rendered entirely with HTML/CSS (no PDF download required)
- `projects.html` + `projects.css` + `projects.js`: cinematic 3D project journey (Three.js, procedural planets)
- `apps.js`: the mini-apps that run directly on the Projects page (add projects in `PROJECTS` inside `projects.js`)
- `assets/vendor/three.module.min.js`: Three.js r160 (MIT), vendored so the page needs no CDN
- `style.css`: Shared Apple Glass visual system
- `script.js`: Avatar interaction
- `assets/`: Logo, favicon, avatar

## Deploy to GitHub Pages
Push the folder contents to a GitHub repository, then enable **Settings → Pages → Deploy from a branch → main → /(root)**.
