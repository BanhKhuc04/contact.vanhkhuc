# VanhKhuc Contact + CV

Static portfolio website for GitHub Pages.

## Files
- `index.html` + `home.css` + `home.js`: portfolio homepage (hero, about, projects, skills, journey, contact)
- `apps.js`: mini-apps that run directly on the homepage ("Dùng ngay") and can be downloaded as single HTML files
- `cv.html` + `style.css`: CV rendered entirely with HTML/CSS
- `projects.html`: redirects to `index.html#projects`
- `assets/`: logo, favicon, avatar

To add a project, add an object to `PROJECTS` in `home.js`.

## Deploy to GitHub Pages
Push the folder contents to a GitHub repository, then enable **Settings → Pages → Deploy from a branch → main → /(root)**.
